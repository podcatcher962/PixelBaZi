## English

**PixelBaZi** is a single-file HTML Chinese Bazi (Four Pillars of Destiny) calculator that generates a pixel-art RPG character card and provides comprehensive fortune analysis with 20+ dimensions including Dayun (Luck Cycle), Ten Gods, Annual Fortune, Spirit Stars, Constellation, Lunar Mansions, and Character Divination.

### ✨ Features

- **Bazi Calculation** — Four Pillars + Na Yin + Five Elements (astronomical algorithm)
- **Pixel RPG Card** — Canvas-drawn character stats card (10 classes + 5 skills)
- **Luck Cycle (Dayun)** — 10 pillars covering ~100 years
- **Ten Gods (Shi Shen)** — Full analysis including hidden stems
- **Annual Fortune** — Current year + 5-year outlook
- **7-Dimension Analysis** — Career / Wealth / Marriage / Education / Health / Fortune / Lifespan
- **Spirit Stars (Shensha)** — Tianyi, Wenchang, Lu, Peach Blossom, etc.
- **Combination/Clash** — Liu He / Liu Chong / Liu Hai / San Xing
- **Celestial** — Zodiac (12 signs) + 28 Lunar Mansions + 7 Luminaries
- **Lucky Numbers** — Based on He Tu / Luo Shu
- **Character Divination (Ce Zi)** — Input any text for glyph-based reading
- **5-Element Radar** — Canvas hexagonal chart
- **Tooltips** — Hover explanations for metaphysical terms
- **Export** — Copy text / Download PNG / Export analysis report
