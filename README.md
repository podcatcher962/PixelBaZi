## 中文

**像素命盘**是一款单文件 HTML 中国传统八字（四柱）命理工具，将命盘生成为像素 RPG 角色卡，同时提供深度命理分析。

| 模块 | 说明 |
|---|---|
| 📜 **八字排盘** | 精准四柱八字 + 纳音 + 五行，基于天文历法算法 |
| 🎮 **像素 RPG 卡** | Canvas 绘制角色属性卡（Lv/HP/MP/ATK/DEF/SPD），10 种职业 + 5 种技能 |
| 🔮 **大运周期** | 顺排/逆排推算，10 步大运覆盖百年人生 |
| ⚖️ **十神格局** | 比劫/食伤/财星/官杀/印星完整分布 |
| 📅 **流年运势** | 本年 + 未来五年逐年分析 |
| 🔍 **七维深析** | 官运·事业 / 家财·财运 / 婚姻·感情 / 升学·学业 / 病逾·健康 / 福祸·总论 / 寿期·根基 |
| ⭐ **神煞** | 天乙贵人/文昌/禄神/桃花/驿马/华盖/羊刃 |
| 🔗 **合冲刑害** | 四柱六合/六冲/六害/三刑关系 |
| 🌠 **星象** | 星座 + 二十八宿 + 七曜日 |
| 🍀 **吉数** | 河图洛书幸运数字 + 方位 + 季节 |
| ✍️ **测字** | 输入任意文字/数字 → 拆字解字 + 命盘互动 |

## English

**PixelBaZi** is a single-file HTML Chinese Bazi (Four Pillars of Destiny) calculator that generates a pixel-art RPG character card and provides in-depth fortune analysis.

### ✨ Features

- Accurate Bazi calculation (Four Pillars + Na Yin + Five Elements)
- Pixel RPG character card (Canvas, 10 classes + 5 skills)
- Luck Cycle (Dayun) calculation (10 pillars, ~100 years)
- Ten Gods (Shi Shen) analysis
- Annual fortune + 5-year outlook
- Seven-dimension deep analysis (Career/Wealth/Marriage/Education/Health/Fortune/Lifespan)
- Spirit Stars (Shensha): Tianyi, Wenchang, etc.
- Combination/Clash relationships
- Constellation + 28 Lunar Mansions + 7 Luminaries
- Lucky numbers (based on He Tu/Luo Shu)
- Character divination (Ce Zi)

For entertainment and cultural reference only. Do not use as basis for important life decisions.
